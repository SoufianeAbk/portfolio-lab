# Abakkiou Soufiane — portfolio

Static Vue 3 portfolio for Abakkiou Soufiane, a junior IT professional. The
site presents approved projects, skills, working process and a public
LinkedIn contact link.

## Requirements

- Node.js 24 LTS
- npm

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

Vite writes the production build to the default `dist/` directory for
deployment on Netlify. The site has no backend, API keys or contact form.
